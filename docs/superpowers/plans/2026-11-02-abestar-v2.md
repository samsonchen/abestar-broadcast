# Abestar v2 Extension Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the Chrome extension for Abestar v2 (`live.abestar.com.tw`): capture final lines only, speak them with no line delay, keep the page at the latest line, and install beside the v1 extension.

**Architecture:** `capture.ts` watches `subtitle-line` elements and sends each line once at `data-status="corrected"`. `follow.ts` polls the feed and clicks "Jump to latest". A per-session database setting, `sessions.tts_release`, keeps v1's one-line delay as the default and lets v2 select immediate release.

**Tech Stack:** TypeScript (strict), Chrome MV3, esbuild, Vitest + jsdom, Playwright, Supabase (Postgres, pgTAP).

**Spec:** `docs/superpowers/specs/2026-11-02-abestar-v2-design.md`

## Global Constraints

- Every Abestar selector lives in `extension/src/content/selectors.ts`.
- `capture.ts` and `follow.ts` take dependencies as arguments and never touch `chrome.*`; `chrome.*` stays in thin `index.ts` files.
- TypeScript strict everywhere, fixtures included. TypeScript stays pinned to `~6.0`.
- `fixtures/logs/*.json` are recorded evidence: never edit or reformat them. `.prettierignore` already covers that folder.
- Only the Supabase project URL and publishable key may be committed.
- Extension name `Abestar Broadcast v2`, version `0.3.0`, output `dist/v2` (local: `dist/v2-local`), zip `abestar-broadcast-v2-0.3.0.zip`.
- Content scripts match `https://live.abestar.com.tw/j/*` and `https://live.abestar.com.tw/listen/*`.
- Timings: draft fallback 10 s, jump after 3 s idle, history window 5 s.
- The installed v1 extension must keep working against the database after migration `0007`.
- Work on a branch, not `main`: `git switch -c abestar-v2`. The owner applies migrations to the hosted project; never run anything against it.
- End every commit message with: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`

## Review Focus

1. **Broadcast started on the language picker:** the feed appears empty, history arrives a moment later, and none of it may be sent. Test in Task 2.
2. **Tab reloaded before the first line was sent:** the history must not be re-sent, because the baseline was already reported to the worker. Tests in Tasks 2 and 3.
3. **Page in a background tab that falls behind with no scroll event:** it must still return to the latest line. Test in Task 4.
4. **Jump button missing or relabelled** (for example, a Chinese interface): the selector must not depend on text, with `scrollTop` as the fallback. Test in Task 4.
5. **Installed v1 calling `start_session` with its old arguments after the migration:** it keeps the one-line delay. Test in Task 5.

```ts
// Records the life of every subtitle line in the format of fixtures/logs/v2-session-*.json.
//
// To record a new log on the real Abestar page, bundle it for the DevTools console:
//   npx esbuild fixtures/raw-logger.ts --format=iife --global-name=rawLogger
// paste the output into the console, then:
//   const log = rawLogger.startRawLogger(document.body);
//   …speak…
//   log.stop(); copy(JSON.stringify(log.records));

export interface RawRecord {
  /** ms since the logger started. */
  t: number;
  ev: 'add' | 'change' | 'gone' | 'MARK';
  /** `data-seg-id`, or `interim`. */
  id?: string;
  tid?: string;
  st?: string | null;
  lang?: string | null;
  text?: string;
  /** Only on MARK: what the recording did at this moment (scroll-up, offline, online, lang-ja, lang-en, end). */
  m?: string;
}

const LINE = '[data-testid="subtitle-line"],[data-testid="subtitle-interim"]';

export function startRawLogger(root: Element): { records: RawRecord[]; stop(): void } {
  const records: RawRecord[] = [];
  const t0 = performance.now();
  const last = new Map<string, string>();

  const scan = () => {
    const t = Math.round(performance.now() - t0);
    const seen = new Set<string>();
    for (const el of Array.from(root.querySelectorAll(LINE))) {
      const line = {
        id: el.getAttribute('data-seg-id') ?? '',
        tid: el.getAttribute('data-testid') ?? '',
        st: el.getAttribute('data-status'),
        lang: el.getAttribute('data-lang') ?? el.getAttribute('lang'),
        text: el.textContent ?? '',
      };
      seen.add(line.id);
      const key = JSON.stringify(line);
      if (last.get(line.id) === key) continue;
      records.push({ t, ev: last.has(line.id) ? 'change' : 'add', ...line });
      last.set(line.id, key);
    }
    for (const id of Array.from(last.keys())) {
      if (seen.has(id)) continue;
      records.push({ t, ev: 'gone', id });
      last.delete(id);
    }
  };

  scan();
  const observer = new MutationObserver(scan);
  observer.observe(root, {
    subtree: true,
    childList: true,
    characterData: true,
    attributes: true,
    attributeFilter: ['data-status', 'data-lang', 'data-seg-id'],
  });
  return { records, stop: () => observer.disconnect() };
}
```

`fixtures/log-digest.ts`:

```ts
// Reduces a log to what capture depends on, so a log recorded from the mock can be compared with a real one.
import type { RawRecord } from './raw-logger';

export interface Step {
  /** e.g. `add:mvy16ds3-37:draft`, `change:mvy16ds3-37:corrected`, `gone:interim`. */
  shape: string;
  /** ms since the first record */
  t: number;
  text?: string;
}

/** Line records (no MARKs), in order within one observer callback, which may differ between page and mock. */
export function digest(log: RawRecord[]): Step[] {
  const lines = log.filter((r) => r.ev !== 'MARK');
  const t0 = lines[0]?.t ?? 0;
  return lines
    .map((r) => {
      const step: Step = {
        shape: [r.ev, r.id, r.st].filter((x) => x != null).join(':'),
        t: r.t - t0,
      };
      if (r.text !== undefined) step.text = r.text;
      return step;
    })
    .sort((a, b) => a.t - b.t || a.shape.localeCompare(b.shape));
}
```

```ts
// Turns a recorded log into steps the mock can replay.
import type { RawRecord } from './raw-logger';

export type TimelineStep =
  | { at: number; action: 'interim'; text: string | null }
  | { at: number; action: 'add'; seq: number; status: string; text: string; lang: string }
  | { at: number; action: 'update'; seq: number; status: string; text: string };

/** A window of v2-session-1.json that starts with no interim and no draft on screen and ends before the recording
 * scrolled back, went offline and switched language. Replaying from mid-line would update lines the mock never saw. */
export const RECORDED_FROM = 7_920;
export const RECORDED_TO = 170_000;

const seqOf = (id: string) => Number(id.split('-').at(-1));

export function timelineFromLog(log: RawRecord[], fromMs: number, toMs: number): TimelineStep[] {
  const steps: TimelineStep[] = [];
  for (const r of log) {
    if (r.ev === 'MARK' || r.t < fromMs || r.t >= toMs || !r.id) continue;
    const at = r.t - fromMs;
    if (r.id === 'interim') {
      steps.push({ at, action: 'interim', text: r.ev === 'gone' ? null : (r.text ?? '') });
    } else if (r.ev === 'add') {
      steps.push({
        at,
        action: 'add',
        seq: seqOf(r.id),
        status: r.st ?? 'draft',
        text: r.text ?? '',
        lang: r.lang ?? 'en',
      });
    } else if (r.ev === 'change') {
      steps.push({
        at,
        action: 'update',
        seq: seqOf(r.id),
        status: r.st ?? 'draft',
        text: r.text ?? '',
      });
    }
  }
  return steps;
}
```

`fixtures/mock-abestar.ts`:

```ts
// Replica of Abestar v2's audience page, enough for capture tests and e2e. Checked against
// fixtures/logs/v2-session-1.json and v2-page-excerpt.html by fixtures/test/mock-fidelity.test.ts.
import type { TimelineStep } from './timeline';

export interface MockLine {
  seq: number;
  status: string;
  text: string;
  lang: string;
}

export interface MockOptions {
  /** Show the language picker first; `enter()` or its button moves on to the feed. */
  picker?: boolean;
  /** Lines the page loads on entering, added in one batch after `historyDelayMs`, as on the real page. */
  history?: MockLine[];
  historyDelayMs?: number;
}

export interface MockAbestar {
  setInterim(text: string | null): void;
  addLine(line: MockLine): void;
  updateLine(seq: number, status: string, text: string): void;
  lines(): MockLine[];
  /** React replacing the feed element, with the same lines. */
  remountFeed(): void;
  /** Leaves the language picker. */
  enter(): void;
  play(steps: TimelineStep[]): void;
  stop(): void;
}

const PREFIX = 'mvy16ds3';
const TEXT_CLASS = 'break-words whitespace-pre-wrap text-[19px] leading-relaxed';
const CARD_CLASS = 'rounded-card bg-surface px-5 py-4 shadow-card';
const BOTTOM_SLOP_PX = 2;

export function mountMock(root: HTMLElement, options: MockOptions = {}): MockAbestar {
  const doc = root.ownerDocument;
  const { picker = false, history = [], historyDelayMs = 70 } = options;
  const timers = new Set<ReturnType<typeof setTimeout>>();
  const lines = new Map<number, { line: MockLine; p: HTMLElement }>();
  let wrapper: HTMLElement | null = null;
  let feed: HTMLElement | null = null;
  let list: HTMLElement | null = null;
  let button: HTMLButtonElement | null = null;
  let interim: HTMLElement | null = null;

  const later = (ms: number, fn: () => void) => {
    const id = setTimeout(() => {
      timers.delete(id);
      fn();
    }, ms);
    timers.add(id);
  };
  const atBottom = (el: HTMLElement) =>
    el.scrollHeight - el.scrollTop - el.clientHeight <= BOTTOM_SLOP_PX;
  const stick = (el: HTMLElement, wasAtBottom: boolean) => {
    if (wasAtBottom) el.scrollTop = el.scrollHeight;
  };
  const card = (p: HTMLElement) => {
    const div = doc.createElement('div');
    div.className = CARD_CLASS;
    div.append(p);
    return div;
  };
  const style = (p: HTMLElement, status: string) => {
    p.setAttribute('data-status', status);
    p.className = `${TEXT_CLASS} ${status === 'corrected' ? 'not-italic text-gray-900' : 'italic text-gray-400'}`;
  };
  const lineElement = (line: MockLine) => {
    const p = doc.createElement('p');
    p.setAttribute('data-testid', 'subtitle-line');
    p.setAttribute('data-seg-id', `${PREFIX}-${line.seq}`);
    p.setAttribute('data-lang', line.lang);
    p.setAttribute('lang', line.lang);
    style(p, line.status);
    p.textContent = line.text;
    return p;
  };

  function mountFeed() {
    wrapper = doc.createElement('div');
    wrapper.className = 'relative flex min-h-0 flex-1 flex-col';
    feed = doc.createElement('div');
    feed.setAttribute('data-testid', 'subtitle-feed');
    feed.setAttribute('aria-live', 'polite');
    feed.className = 'min-h-0 flex-1 overflow-x-hidden overflow-y-auto overscroll-contain';
    list = doc.createElement('div');
    list.className = 'flex flex-col gap-3 px-4 py-4';
    feed.append(list);
    button = doc.createElement('button');
    button.type = 'button';
    button.className = 'btn-primary absolute bottom-4 left-1/2 h-10 rounded-full px-5 shadow-pop';
    button.textContent = 'Jump to latest';
    button.hidden = true;
    const currentFeed = feed;
    const currentButton = button;
    button.addEventListener('click', () => {
      currentFeed.scrollTop = currentFeed.scrollHeight;
      currentButton.hidden = true;
    });
    feed.addEventListener('scroll', () => {
      currentButton.hidden = atBottom(currentFeed);
    });
    wrapper.append(feed, button);
    root.replaceChildren(wrapper);
  }

  const mock: MockAbestar = {
    setInterim(text) {
      if (!list || !feed) return;
      const bottom = atBottom(feed);
      if (text === null) {
        interim?.parentElement?.remove();
        interim = null;
      } else if (interim) {
        (interim.firstChild as Text).data = text;
      } else {
        interim = doc.createElement('p');
        interim.setAttribute('data-testid', 'subtitle-interim');
        interim.setAttribute('data-seg-id', 'interim');
        style(interim, 'draft');
        interim.append(doc.createTextNode(text));
        const div = card(interim);
        div.setAttribute('aria-hidden', 'true');
        list.append(div);
      }
      stick(feed, bottom);
    },

    addLine(line) {
      if (!list || !feed) return;
      const bottom = atBottom(feed);
      const p = lineElement(line);
      lines.set(line.seq, { line: { ...line }, p });
      const div = card(p);
      if (interim?.parentElement) list.insertBefore(div, interim.parentElement);
      else list.append(div);
      stick(feed, bottom);
    },

    updateLine(seq, status, text) {
      const entry = lines.get(seq);
      if (!entry) throw new Error(`no line ${seq}`);
      entry.line.status = status;
      entry.line.text = text;
      style(entry.p, status);
      entry.p.textContent = text;
    },

    lines: () => Array.from(lines.values(), (e) => ({ ...e.line })),

    remountFeed() {
      mountFeed();
      const current = Array.from(lines.values(), (e) => e.line);
      lines.clear();
      interim = null;
      for (const line of current) mock.addLine(line);
    },

    enter() {
      mountFeed();
      later(historyDelayMs, () => {
        for (const line of history) mock.addLine(line);
      });
    },

    play(steps) {
      for (const step of steps) {
        later(step.at, () => {
          if (step.action === 'interim') mock.setInterim(step.text);
          else if (step.action === 'add') mock.addLine(step);
          else mock.updateLine(step.seq, step.status, step.text);
        });
      }
    },

    stop() {
      for (const id of timers) clearTimeout(id);
      timers.clear();
    },
  };

  if (picker) {
    const select = doc.createElement('select');
    select.setAttribute('data-testid', 'target-lang-select');
    const enter = doc.createElement('button');
    enter.id = 'enter-event';
    enter.textContent = 'Enter event';
    enter.addEventListener('click', () => mock.enter());
    root.replaceChildren(select, enter);
  } else {
    mock.enter();
  }
  return mock;
}
```

```ts
// Wires the toolbar of mock-abestar.html to the mock. Lines live in sessionStorage so a reload shows them again, like
// the real page's history, and `?picker` starts on the language picker.
import { mountMock, type MockLine } from './mock-abestar';
import { RECORDED_FROM, RECORDED_TO, timelineFromLog } from './timeline';
import type { RawRecord } from './raw-logger';
import log from './logs/v2-session-1.json';

const STORAGE = 'mock-lines';
const CORRECTION_MS = 800;
const params = new URLSearchParams(location.search);
const saved = JSON.parse(sessionStorage.getItem(STORAGE) ?? '[]') as MockLine[];

const mock = mountMock(document.querySelector<HTMLElement>('#app') as HTMLElement, {
  picker: params.has('picker'),
  history: saved,
});
const save = () => sessionStorage.setItem(STORAGE, JSON.stringify(mock.lines()));
const textInput = document.querySelector<HTMLInputElement>('#text') as HTMLInputElement;
const on = (id: string, fn: () => void) =>
  document.querySelector(`#${id}`)?.addEventListener('click', fn);

const nextSeq = () =>
  Math.max(0, ...saved.map((l) => l.seq), ...mock.lines().map((l) => l.seq)) + 1;

/** One line's life: interim, then draft, then corrected with different text. */
on('say', () => {
  const seq = nextSeq();
  const text = textInput.value || `Sentence number ${seq}.`;
  mock.setInterim(`Interim ${text}`);
  mock.setInterim(null);
  mock.addLine({ seq, status: 'draft', text: `Draft ${text}`, lang: 'en' });
  save();
  setTimeout(() => {
    mock.updateLine(seq, 'corrected', text);
    save();
  }, CORRECTION_MS);
});
/** A line that stays a draft, for the 10 s fallback. */
on('stuck', () => {
  const seq = nextSeq();
  mock.addLine({ seq, status: 'draft', text: textInput.value || `Stuck ${seq}.`, lang: 'en' });
  save();
});
const replay = () => mock.play(timelineFromLog(log as RawRecord[], RECORDED_FROM, RECORDED_TO));
on('play', replay);
on('forget', () => sessionStorage.removeItem(STORAGE));

if (params.has('autoplay')) replay();
```

```ts
// Turns Abestar's subtitle feed into CaptureMessages. Pure DOM logic: content/index.ts connects it to the worker.
// A line is sent once, when it is final. See docs/superpowers/specs/2026-11-02-abestar-v2-design.md.

import type { CaptureMessage } from '@abestar/shared';
import { CORRECTED, FEED, LINE, SEG_ID } from './selectors';

export interface CaptureOptions {
  /** After a reload: lines up to here were already sent. Null: this is a new broadcast, take it from the page. */
  resumeAfterSeq?: number | null;
  /** A line still not final after this long is sent as it is. */
  draftTimeoutMs?: number;
  /** How long an empty feed may wait for its history before counting as an event with none. */
  historyWindowMs?: number;
  /** How long to wait for the feed before reporting `column-not-found`. */
  feedTimeoutMs?: number;
}

export interface Capture {
  stop(): void;
}

type Timer = ReturnType<typeof setTimeout>;

const OBSERVE: MutationObserverInit = {
  subtree: true,
  childList: true,
  characterData: true,
  attributes: true,
  attributeFilter: ['data-status'],
};

export function startCapture(
  doc: Document,
  send: (message: CaptureMessage) => void,
  {
    resumeAfterSeq = null,
    draftTimeoutMs = 10_000,
    historyWindowMs = 5_000,
    feedTimeoutMs = 10_000,
  }: CaptureOptions = {},
): Capture {
  /** Lines at or below this are not sent. Null until known. */
  let baseline = resumeAfterSeq;
  /** Lines sent with their final text. */
  const finished = new Set<number>();
  /** Lines sent by the draft timeout, which may still be corrected. */
  const sentAsDraft = new Set<number>();
  const draftTimers = new Map<number, Timer>();
  let feed: Element | null = null;
  let notFoundTimer: Timer | undefined;
  let historyTimer: Timer | undefined;

  const seqOf = (line: Element): number | null => {
    const match = SEG_ID.exec(line.getAttribute('data-seg-id') ?? '');
    return match ? Number(match[1]) : null;
  };
  const textOf = (line: Element) => line.textContent?.trim() ?? '';
  const isFinal = (line: Element) => line.getAttribute('data-status') === CORRECTED;
  const linesIn = (root: ParentNode) => Array.from(root.querySelectorAll(LINE));

  const sendLine = (line: Element, seq: number, text: string) =>
    send({ kind: 'segment', seq, text, lang: line.getAttribute('lang') });

  function draftTimedOut(seq: number) {
    draftTimers.delete(seq);
    if (!feed) return;
    const line = linesIn(feed).find((el) => seqOf(el) === seq);
    const text = line ? textOf(line) : '';
    if (!line || !text || isFinal(line)) return;
    sentAsDraft.add(seq);
    sendLine(line, seq, text);
  }

  function scan() {
    if (!feed || baseline === null) return;
    for (const line of linesIn(feed)) {
      const seq = seqOf(line);
      if (seq === null || seq <= baseline || finished.has(seq)) continue;
      const text = textOf(line);
      if (isFinal(line)) {
        if (!text) continue;
        clearTimeout(draftTimers.get(seq));
        draftTimers.delete(seq);
        finished.add(seq);
        sendLine(line, seq, text);
      } else if (!draftTimers.has(seq) && !sentAsDraft.has(seq)) {
        draftTimers.set(
          seq,
          setTimeout(() => draftTimedOut(seq), draftTimeoutMs),
        );
      }
    }
  }

  /** Whatever is final on screen now is history. Drafts are still to come. */
  function takeBaseline() {
    clearTimeout(historyTimer);
    historyTimer = undefined;
    if (!feed) return; // replaced during the window: attach() arms the timer again
    const seqs = linesIn(feed)
      .filter(isFinal)
      .map(seqOf)
      .filter((seq) => seq !== null);
    baseline = Math.max(0, ...seqs);
    send({ kind: 'baseline', seq: baseline });
    scan();
  }

  const feedObserver = new MutationObserver(() => {
    if (baseline === null) {
      if (feed && linesIn(feed).length > 0) takeBaseline();
    } else {
      scan();
    }
  });

  function waitForFeed() {
    clearTimeout(notFoundTimer);
    notFoundTimer = setTimeout(
      () => send({ kind: 'status', status: 'column-not-found' }),
      feedTimeoutMs,
    );
  }

  function attach(found: Element) {
    feed = found;
    clearTimeout(notFoundTimer);
    send({ kind: 'status', status: 'ok' });
    feedObserver.observe(found, OBSERVE);
    if (baseline !== null) scan();
    else if (linesIn(found).length > 0) takeBaseline();
    else historyTimer ??= setTimeout(takeBaseline, historyWindowMs);
  }

  function detach() {
    feedObserver.disconnect();
    feed = null;
    send({ kind: 'status', status: 'detached' });
    waitForFeed();
  }

  // The feed appears after the language picker, and React may replace it.
  const pageObserver = new MutationObserver(() => {
    if (feed && !feed.isConnected) detach();
    if (!feed) {
      const found = doc.querySelector(FEED);
      if (found) attach(found);
    }
  });
  pageObserver.observe(doc, { subtree: true, childList: true });
  const initial = doc.querySelector(FEED);
  if (initial) attach(initial);
  else waitForFeed();

  return {
    stop() {
      pageObserver.disconnect();
      feedObserver.disconnect();
      clearTimeout(notFoundTimer);
      clearTimeout(historyTimer);
      for (const timer of draftTimers.values()) clearTimeout(timer);
      draftTimers.clear();
    },
  };
}
```

A first batch of lines always counts as history, so on an empty event a line that arrives already final within the first moments is not sent. That is accepted: a first line normally starts as a draft, which is sent, and an event with no lines yet has no audience to miss it.

```ts
});
```

```ts
  await this.update({ broadcast: raiseLastSeq(message.seq) });
} else if (message.kind === 'status') {
  if (message.status === 'column-not-found') await this.update({ status: 'column-not-found' });
  else if (message.status === 'ok' && this.state.status !== 'reconnecting')
    await this.update({ status: 'live' });
} else {
  const item = {
    epoch: broadcast.epoch,
    seq: message.seq,
    text: message.text,
    lang: message.lang,
  };
  const i = this.queue.findIndex((q) => q.epoch === item.epoch && q.seq === item.seq);
  // Not yet sent: only the newest text matters.
  if (i > 0 || (i === 0 && !this.flushing)) this.queue[i] = item;
  else this.queue.push(item);
  await this.update({ broadcast: raiseLastSeq(message.seq) });
  void this.flush();
}
```

```ts
// Keeps Abestar's feed at the latest line while the broadcast runs: a page left scrolled back, by accident or not,
// returns 3 s after the last scroll. Capture does not depend on this; it is for whoever watches the page.

import { FEED, JUMP_BUTTON } from './selectors';

export interface Follow {
  stop(): void;
}

export interface FollowOptions {
  /** How long after the last scroll to return. */
  idleMs?: number;
  /** How often to check. A timer, because a page that falls behind in a background tab fires no scroll event. */
  checkMs?: number;
}

const BOTTOM_SLOP_PX = 2;

export function followLatest(
  doc: Document,
  { idleMs = 3_000, checkMs = 500 }: FollowOptions = {},
): Follow {
  let lastScroll = Date.now();

  // Scroll events do not bubble; the capture phase also covers a feed React has replaced.
  const onScroll = (event: Event) => {
    if (event.target instanceof Element && event.target.matches(FEED)) lastScroll = Date.now();
  };
  doc.addEventListener('scroll', onScroll, true);

  const check = setInterval(() => {
    const feed = doc.querySelector(FEED);
    if (!feed) return;
    const behind = feed.scrollHeight - feed.scrollTop - feed.clientHeight > BOTTOM_SLOP_PX;
    if (!behind || Date.now() - lastScroll < idleMs) return;
    const button = doc.querySelector<HTMLElement>(JUMP_BUTTON);
    // The mock and the real page both remove or hide it when not needed; a click on a hidden one is harmless.
    button?.click();
    // Also the fallback: the page's own click handler may be gone or renamed. Setting it twice is harmless.
    feed.scrollTop = feed.scrollHeight;
  }, checkMs);

  return {
    stop() {
      clearInterval(check);
      doc.removeEventListener('scroll', onScroll, true);
    },
  };
}
```

```sql
-- When a line is spoken, per session. 'next_line' (the default): one line behind, for the Abestar v1 extension, whose
-- lines may still change. 'final': as soon as it is inserted, for the Abestar v2 extension, which sends only final
-- lines. An update never speaks a line again, in either mode.

alter table public.sessions
  add column tts_release text not null default 'next_line'
  check (tts_release in ('next_line', 'final'));

alter table private.tts_jobs drop constraint tts_jobs_released_by_check;
alter table private.tts_jobs
  add constraint tts_jobs_released_by_check check (released_by in ('next_line', 'pause', 'final'));

drop function public.start_session(text, text, text, boolean, text, boolean);
create function public.start_session(
  p_token text,
  p_title text,
  p_target_lang text default null,
  p_force boolean default false,
  p_voice text default 'female',
  p_tts boolean default false,
  p_tts_release text default 'next_line'
) returns jsonb
language plpgsql security definer set search_path = '' as $$
declare
  v_live uuid;
  v_prev_pin text;
  v_pin text;
  v_id uuid;
begin
  perform private.check_token(p_token);

  select id into v_live from public.sessions where status = 'live' for update;
  if found then
    if not p_force then
      raise exception 'session_live' using errcode = 'PT409';
    end if;
    update public.sessions set status = 'ended', ended_at = now() where id = v_live;
  end if;

  -- A new PIN never equals the previous session's, so an old QR code cannot open the new talk.
  select p.pin into v_prev_pin
  from private.session_pins p join public.sessions s on s.id = p.session_id
  order by s.created_at desc limit 1;
  loop
    v_pin := private.random_pin();
    exit when v_pin is distinct from v_prev_pin;
  end loop;

  insert into public.sessions (title, target_lang, tts_voice, tts_on, tts_release)
  values (p_title, p_target_lang, coalesce(p_voice, 'female'), coalesce(p_tts, false), coalesce(p_tts_release, 'next_line'))
  returning id into v_id;
  insert into private.session_pins (session_id, pin) values (v_id, v_pin);
  return jsonb_build_object('id', v_id, 'pin', v_pin);
end;
$$;
revoke execute on function public.start_session(text, text, text, boolean, text, boolean, text) from public, anon, authenticated;
grant execute on function public.start_session(text, text, text, boolean, text, boolean, text) to anon, authenticated;

create or replace function private.segments_tts_release() returns trigger
language plpgsql set search_path = '' as $$
declare
  v_previous record;
begin
  begin
    if (select tts_release from public.sessions where id = new.session_id) = 'final' then
      perform private.tts_enqueue(new.session_id, new.epoch, new.seq, 'final');
      return null;
    end if;

    select epoch, seq into v_previous from public.segments
    where session_id = new.session_id and (epoch, seq) < (new.epoch, new.seq)
    order by epoch desc, seq desc limit 1;
    if found then
      perform private.tts_enqueue(new.session_id, v_previous.epoch, v_previous.seq, 'next_line');
    end if;
    if exists (
      select 1 from public.segments
      where session_id = new.session_id and (epoch, seq) > (new.epoch, new.seq)
    ) then
      perform private.tts_enqueue(new.session_id, new.epoch, new.seq, 'next_line');
    end if;
  exception when others then
    raise warning 'tts release failed: %', sqlerrm;
  end;
  return null;
end;
$$;

create or replace function private.tts_flush() returns void
language plpgsql set search_path = '' as $$
declare
  v_settings private.tts_settings;
  v_last record;
begin
  select * into v_settings from private.tts_settings;
  if not v_settings.enabled or v_settings.quiet_flush_seconds = 0 then
    return;
  end if;
  for v_last in
    select g.session_id, g.epoch, g.seq, g.updated_at
    from public.sessions s
    cross join lateral (
      select session_id, epoch, seq, updated_at from public.segments
      where session_id = s.id order by epoch desc, seq desc limit 1
    ) g
    where s.status = 'live' and s.tts_release = 'next_line'
  loop
    if v_last.updated_at <= now() - make_interval(secs => v_settings.quiet_flush_seconds) then
      perform private.tts_enqueue(v_last.session_id, v_last.epoch, v_last.seq, 'pause');
    end if;
  end loop;
end;
$$;
```

```js
const { chromium } = require('playwright');
(async () => {
  const b = await chromium.launch({ headless: false });
  const ctx = await b.newContext();
  const p = await ctx.newPage();
  await p.goto('https://live.abestar.com.tw/j/AJM-0256');
  await p.waitForSelector('[data-testid="target-lang-select"]');
  await p.selectOption('[data-testid="target-lang-select"]', 'en');
  await p.getByRole('button', { name: 'Enter event' }).click();
  await p.waitForSelector('[data-testid="subtitle-feed"]');
  await p.evaluate(() => {
    window.__log = [];
    const t0 = performance.now();
    const seen = new Set();
    new MutationObserver(() => {
      for (const el of document.querySelectorAll(
        '[data-testid=subtitle-line][data-status=corrected]',
      )) {
        const id = el.getAttribute('data-seg-id');
        if (!seen.has(id)) {
          seen.add(id);
          window.__log.push([Math.round(performance.now() - t0), id, document.hidden]);
        }
      }
    }).observe(document.body, {
      subtree: true,
      childList: true,
      attributes: true,
      characterData: true,
    });
  });
  const front = await ctx.newPage();
  await front.goto('about:blank');
  await front.bringToFront();
  await front.waitForTimeout(90000);
  const r = await p.evaluate(() => {
    const f = document.querySelector('[data-testid=subtitle-feed]');
    return {
      log: window.__log,
      hidden: document.hidden,
      gap: f.scrollHeight - f.scrollTop - f.clientHeight,
    };
  });
  console.log(JSON.stringify(r));
  await b.close();
})();
```
